# abottom.org

Static site exported from pmillspaugh/abottom-dot-org on Val Town, main version 72.
The HTML is preserved unchanged. No dependencies, secrets, or build step are required.

## Render

Create a Static Site from this repository with build command `true` and publish directory `.`.
Alternatively, create a Render Blueprint using render.yaml.

Verify the onrender.com deployment before adding abottom.org and changing its DNS.
Keep the Val Town deployment available until the custom domain is working on Render.
